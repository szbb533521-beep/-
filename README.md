周易玩辞白话研读
品读古人智慧，思考人生进退。
本技能以南宋项安世《周易玩辞》为核心，结合十六卷白话译本，帮助你读懂卦辞、爻辞背后的含义，理解古人如何观察变化、把握时机、权衡得失。
“玩辞”，就是反复品味文字、深入体会道理。通过本技能，你可以从具体问题出发，逐步走进《周易》的思想世界。
主要功能
- 全书白话解读
  收录十六卷、982 个条目的白话译文，配套 373 页 PDF，让古籍更容易阅读。
- 卦爻与主题检索
  按卦名、爻位或关键词查找内容，围绕进退、学习、处世、人际关系等主题展开研读。
- 讲清古人的思考过程
  结合词义、卦象和爻位，解释项安世为什么作出这样的判断，帮助你理解论证，而不只记住结论。
- 联系生活，提供思考角度
  将书中的智慧与家庭相处、工作选择、沟通取舍等情境联系起来，探讨何时行动、何时等待，以及如何把握分寸。
- 注明出处，方便回查
  提供卷次、原扫描页码和白话译本页码，区分作者观点、译者说明与现代引申。
如何使用
你可以直接提问：
“潜龙勿用”对刚开始一项事业有什么启发？
项安世怎样理解“和而不同”？
帮我比较损卦与益卦中的取舍智慧。
最近准备去长辈家，能从睽卦中得到哪些相处建议？

也可以提出数字取卦的需求。在对话中先明确对应规则，再检索相关卦义作文化参考；当前技能主要提供研读与检索，尚未内置铜钱起卦或完整占筮程序。
古人智慧，今天仍可细读
面对变化，懂得审时度势；面对分歧，学会求同存异；面对顺境，保持谦逊与警醒；面对困境，寻找可以行动的空间。
本技能希望帮助你把古籍中的文字，转化为观察处境、反思选择的工具。
本译本为 AI 辅助译写的白话阅读本，少数字句存疑已随文标注。相关解读用于学习与思考，不作为准确预测吉凶、财运、婚姻等未来结果的依据。
